# Branding

## Logo Usage

The project logo is used as the official visual identity of this project.

Please use the logo in its original form and avoid modifications or uses that may cause confusion about the identity, ownership, or affiliation of the project.

If you would like to use the logo for purposes beyond referencing this project, please contact the maintainers.

---

## Project Name

The project name `gald-lang` may be used to refer to the project in documentation, articles, and discussions.

Please avoid using the project name or logo in ways that imply endorsement, sponsorship, or official affiliation.

---

## Community Usage

You are welcome to:

- Write tutorials
- Create videos
- Reference the project
- Link to the official repository

As long as such use does not create confusion about the origin or official status of the project.
